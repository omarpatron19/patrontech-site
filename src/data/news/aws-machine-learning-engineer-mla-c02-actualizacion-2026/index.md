## Nueva versión de la certificación

AWS está actualizando **Machine Learning Engineer - Associate**. El registro para la beta de **MLA-C02** abre el **1 de septiembre de 2026** y el último día para presentar **MLA-C01 en inglés** será el **28 de septiembre de 2026**.

AWS explica que la nueva versión amplía el alcance para validar tanto machine learning tradicional como **generative AI**, incluyendo servicios como Amazon SageMaker AI y Amazon Bedrock.

## ¿MLA-C01 o MLA-C02?

Quien ya esté preparado para MLA-C01 todavía puede presentar la versión actual dentro del calendario publicado por AWS. Si tu objetivo es que la certificación refleje capacidades más recientes de GenAI y workloads agentic, MLA-C02 es la versión que conviene vigilar.
