## Maintenance además de recertificación

AWS anunció el **23 de junio de 2026** una nueva opción en beta para mantener certificaciones seleccionadas mediante cursos y laboratorios hands-on de **AWS Skill Builder**, en lugar de depender únicamente de volver a presentar un examen.

La opción agrega **un año** de vigencia a partir de la finalización de las actividades de maintenance.

## Qué certificaciones soporta inicialmente

AWS anunció soporte inicial para:

- Solutions Architect - Associate
- Developer - Associate
- CloudOps Engineer - Associate
- DevOps Engineer - Professional
- Solutions Architect - Professional

AWS también anunció que más certificaciones se incorporarán posteriormente. Por eso no debe asumirse que esta opción ya aplica a todo el catálogo.
