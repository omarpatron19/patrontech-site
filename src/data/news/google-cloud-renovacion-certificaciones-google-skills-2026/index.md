## Una nueva forma de mantener la certificación

Google Cloud anunció el **8 de julio de 2026** que determinadas certificaciones pueden renovarse mediante cursos y **skill badges** designados dentro de Google Skills.

Al completar las actividades requeridas mientras la certificación continúa activa, la credencial se extiende **un año**.

## Credenciales disponibles en el lanzamiento

La opción está disponible inicialmente para:

- Cloud Digital Leader
- Associate Cloud Engineer
- Professional Cloud Architect
- Professional Data Engineer

Esto no significa que todas las certificaciones de Google Cloud tengan ya la misma opción. Para las demás credenciales debes revisar sus mecanismos de renovación oficiales.
