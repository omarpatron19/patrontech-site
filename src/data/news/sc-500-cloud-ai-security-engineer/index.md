## Una nueva ruta para seguridad cloud y AI

**Microsoft Certified: Cloud and AI Security Engineer Associate** valida la capacidad de diseñar, implementar y administrar controles de seguridad end-to-end en **Azure, entornos híbridos y escenarios habilitados con inteligencia artificial**.

El enfoque incluye la protección de identidades, datos, aplicaciones e infraestructura, además de consideraciones de cumplimiento. Para profesionales de Azure Security es una certificación especialmente relevante porque el portfolio está cambiando al mismo tiempo que **AZ-500** entra en retiro.

## Cómo ubicarla en una ruta

Una ruta de aprendizaje puede comenzar con **SC-900** y avanzar hacia SC-500 para profundizar en seguridad técnica. Si tu objetivo es **SC-100 Cybersecurity Architect Expert**, revisa los prerequisites oficiales de SC-100 antes de asumir equivalencias.
