## Transición de la ruta híbrida de Windows Server

Microsoft anunció que los exámenes **AZ-800** y **AZ-801** se retiran el **30 de septiembre de 2026**. Durante la transición todavía pueden aparecer asociados a la ruta histórica de Windows Server Hybrid Administrator.

La nueva certificación **Windows Server Administrator Associate** se encuentra en beta y Microsoft indica que, una vez retirados AZ-800 y AZ-801, **AZ-802** quedará como la ruta disponible para obtenerla.

## Qué significa para candidatos

Si ya llevas avance importante en AZ-800 y AZ-801, revisa las fechas y condiciones antes de cambiar de plan. Si apenas comenzarás, compara los objetivos de **AZ-802** con tu experiencia en AD DS, administración híbrida, máquinas virtuales, networking, storage, seguridad y troubleshooting.
